# Mthwana Logistics Website

## Project Description
This website for Mthwana Logistics is built using HTML, CSS, and JavaScript to deliver a professional, responsive, and interactive user experience. It features a consistent navigation menu with active link highlighting, a fully responsive layout optimized for desktop, tablet, and mobile screens, and clear page structures with well-organized headings and meta descriptions for SEO.

JavaScript enhances the site with interactive components such as an accordion for service details, a lightbox image gallery to view fleet photos, and an embedded interactive map displaying company locations using Leaflet.js. Both the enquiry and contact forms include client-side validation with clear error messages to ensure accurate user input, while the contact form compiles user input into an email link.
